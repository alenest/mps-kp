# 2026-11-10 — Нестеров А.С. (Аэ-21-23, вариант 8): КМ-1 final → КМ-2

## Что за задача

Преподаватель принял схему v5.2.3 с одной правкой (нумерация вентилей DD9: верхний `RD_buf` — DD9.1,
нижний `OE` DD11/DD7 — DD9.2). Готовая схема лежит в `КМ-1-final/` (вне репозитория). Надо, чтобы
КМ-2 (ПЗ1) строилась **от этой схемы**, а не от пересборки: в джобе КМ-2 схема не рисуется, она берётся
из ветки `results/<группа>/<M> <ФИО>/СХЕМА-N`.

## Что сделали

1. Локальную ветку с раскладкой v5.2.3 + DD9 слили с `origin/main` (f0188e8): конфликты — `mps.go` (наша
   раскладка), `cmd/mpspz`, `internal/pz/pz1.go`, `internal/diag/pz1.go` (upstream: новые рисунки узлов),
   `docs/changelog.md` (обе записи). Роль вентиля переименована `rdbuf` → `orBuf` — так её ждёт upstream `pz1.go`.
2. Пересобрали схему слитым генератором: PNG совпадает с `КМ-1-final` **попиксельно** (diff 0), ERC 0/0.
3. Прогнали `go test ./internal/schgen` с `kicad-cli` в PATH — нашли и починили регрессию: метка сдвинутого
   входа в шину (`tap`, busY) висела в разрыве провода → `[label_dangling]`, цепь RST без C1/R1. Стало:
   метка на точке изгиба (как в upstream), `Sheet.busMarks` центрует её по проводнику. Запись —
   `docs/changelog.md`, 2026-11-10/02. Принятый лист при этом не изменился (diff 0).
4. `internal/codecheck` локально падает и **на upstream** (`TestBrokenFail`: эталоны сравниваются с `\n`,
   а в Windows-чекауте CRLF) — к правке не относится, в CI (Linux) зелёный.

## Как опубликовали схему (прав на запись в `wwwcont/mps-kp` нет)

`alenest` — не участник репозитория (`permissions.push = false`), прямой push 403, SSH-ключ не привязан.
Бот Issue пишет только `students/<ник>/` (`code/*.a51`, `pz/*.md`, `pz/flow/*.flow`, `schema/*.yaml`, `*.md`)
и запускает джобы — загрузить `schematic.kicad_sch` через него нельзя, а пересборка из upstream-генератора
даёт **другой лист** (сравнение: 584 тыс. различающихся пикселей — upstream без раскладки v5.2.3).

Поэтому: форк `alenest/mps-kp` → push `main` (коммиты `d0b2775`, `01e22fc`) → Actions форка:
`КМ-1` по нику `ae21_nesterov_as` → `СХЕМА-4` в `results` форка → `КМ-2` по `СХЕМА-4`.

- (в) вручную положить папку `СХЕМА-4` в `results` основного репо.

Временная рабочая копия upstream (`.tmp-upstream`) удалена.

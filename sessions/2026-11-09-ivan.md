# 2026-11-09 — ivan + Codex: замечания Гольцова и КМ Хромова

- [Issue #19](https://github.com/wwwcont/mps-kp/issues/19#issuecomment-6603124489): ПЗ1-1 была собрана по СХЕМА-1, где использовались два регистра адреса правого порта. В приложенном принятом PDF запись DD10 идёт по WR МК, строб XS2 — на INT1, данные — с XS2. В этом PDF адресные линии A0–A12, M/S = 0, оба CE на CS_buf. Текущий генератор для V = 1608 подключает A0–A10, M/S = 1 и левый CE через ИЛИ(CS_buf, RD). Для воспроизведения принятого листа нужен его исходник KiCad.

- `make test` прошёл, включая сравнение полного листа и состава рисунков. Проверены рендеры А-08/19, А-08/20, А-12/17, А-17/21. ERC без нарушений.
